# Bubble-tea-website
A modern, responsive website showcasing a bubble tea shop menu with vibrant images, interactive ordering form, and smooth animations using HTML, CSS, JavaScript, and Bootstrap 5. Features include:

Fully responsive design for mobile, tablet, and desktop

Interactive bubble tea menu with enlarged product images and “Buy Now” buttons

Order form with live selection and submission alert

Smooth ScrollReveal animations for a dynamic user experience

Clean layout with About, Contact, and Footer sections

Customizable styles with a bubble-tea-themed color palette
